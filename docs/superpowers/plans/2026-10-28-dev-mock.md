# Dashboard mock and `pnpm dev:mock` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command (`pnpm dev:mock`) opens the dashboard against the existing stats stub, signed in, with Node pinned to 24.

**Architecture:** `mock/dev.mjs` starts `mock/stats-stub/server.mjs` on 8099, waits until it answers, then starts `vue-cli-service serve --mode mock` on 8080. `.env.mock` aims the existing webpack proxy at the stub. `mock/session.js` writes a dummy token before mount when `VUE_APP_MOCK=1`. The stub gains login and refresh POSTs so logout is not a dead end.

**Tech Stack:** Node 24, pnpm 9.0.6, Vue CLI 5 (`--mode mock`), vitest, existing `mock/stats-stub` (no new npm dependency).

### Task 2: `seedMockSession`

**Files:**
- Create: `mock/session.js`

**Interfaces:**
- Consumes: a Storage-like `{ getItem(key), setItem(key, value) }`; default argument `localStorage`
- Produces: `export function seedMockSession(storage = localStorage)`

| Key | Value |
|---|---|
| `access_token` | `mock-access` |
| `refresh_token` | `mock-refresh` |
| `expires_at` | `2000000000` |
| `user` | `{"id":1,"username":"casaos","nickname":"casaos","role":"admin","avatar":"","description":""}` |

function memoryStorage(initial = {}) {
	const data = { ...initial }
	return {
		getItem: key => (Object.hasOwn(data, key) ? data[key] : null),
		setItem: (key, value) => { data[key] = String(value) },
		data,
	}
}

describe('seedMockSession', () => {
	it('writes the four keys when storage is empty', () => {
		const storage = memoryStorage()

		expect(storage.getItem('user')).toBe('old')

	id: 1,
	username: 'casaos',
	nickname: 'casaos',
	role: 'admin',

- [ ] **Step 4: `mock/dev.mjs`**

```js
import { spawn } from 'node:child_process'
import { request } from 'node:http'
import { fileURLToPath } from 'node:url'
import process from 'node:process'
import path from 'node:path'

const root = path.dirname(fileURLToPath(new URL('.', import.meta.url)))
const STUB_PORT = 8099
const WAIT_MS = 5000

function waitForStub(deadline) {
	return new Promise((resolve, reject) => {
		const tryOnce = () => {
			const req = request({ host: '127.0.0.1', port: STUB_PORT, path: '/v1/users/status' }, (res) => {
				res.resume()
				if (res.statusCode === 200) {
					resolve()
					return
				}
				retry()
			})
			req.on('error', retry)
			req.end()
		}
		const retry = () => {
			if (Date.now() > deadline) {
				reject(new Error('stats stub did not answer on 127.0.0.1:8099'))
				return
			}
			setTimeout(tryOnce, 100)
		}
		tryOnce()
	})
}

function kill(child) {
	if (child && child.exitCode === null && child.signalCode === null) {
		child.kill('SIGTERM')
	}
}

const stub = spawn(process.execPath, ['mock/stats-stub/server.mjs', '--port', String(STUB_PORT)], {
	cwd: root,
	stdio: 'inherit',
})

try {
	await waitForStub(Date.now() + WAIT_MS)
} catch (error) {
	kill(stub)
	console.error(error.message)
	process.exit(1)
}

const vue = spawn('pnpm', ['exec', 'vue-cli-service', 'serve', '--mode', 'mock'], {
	cwd: root,
	stdio: 'inherit',
})

let stopping = false
const stop = (code) => {
	if (stopping) {
		return
	}
	stopping = true
	kill(vue)
	kill(stub)
	process.exit(code)
}

process.on('SIGINT', () => stop(0))
process.on('SIGTERM', () => stop(0))
vue.on('exit', (code, signal) => {
	if (stopping) {
		return
	}
	kill(stub)
	process.exit(code ?? (signal ? 1 : 0))
})
stub.on('exit', () => {
	if (stopping) {
		return
	}
	kill(vue)
	process.exit(1)
})
```

`root` is the `mock/` directory if `new URL('.', import.meta.url)` is the file's folder — **fix:** `mock/dev.mjs` lives in `mock/`, so `root` must be the repository root (`path.dirname(fileURLToPath(import.meta.url))` then `path.dirname` once more, or `fileURLToPath(new URL('..', import.meta.url))`). Use:

```js
const root = fileURLToPath(new URL('..', import.meta.url))
```
